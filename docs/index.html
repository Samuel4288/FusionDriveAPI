Some notes:

Material, thickness and finishing must be retrieved from GetRequirements function.(only pick name property,not ID)
Those are lists that cannot be edited and are common to all clients
Only StoneName and Classname are unique to each client.

GetSlabBySerialNumber can have mutliple slabs,scanner allows duplicates.

Client must be organized and keep one only.

AddSlabs function returns id of the slab just added, but only when one is added. If multiple are added, only last ID is showed.

It is recommended to add one at a time to keep the ID. If multiple are added,you can retrieve the ID by using GetSlabBySerialNumber.

For adding Slabs,function addSlabsDirect is considerably faster than AddSlabs, but requires to fetch ClassID before sending the slabs.

Function getInventoryCatalog returns all Material,StoneName,Classname,Thickness,Finishing and ClassID so you can check easily.

Reason is that ClassID contains Material,StoneName,Classname,Thickness,Finishing.

AddSlabs is slower because it needs to create the classID(or check if it exists) before adding the slab.
